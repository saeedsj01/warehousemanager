# سامانه مدیریت انبار - نسخه اولیه Laravel

این پروژه برای اجرا در Windows و Laravel Herd آماده شده است. دیتابیس پیش‌فرض SQLite است و نیازی به نصب یا تنظیم SQL Server / MySQL ندارد.

## پیش‌نیازها

- Laravel Herd برای Windows
- PHP 8.2 یا بالاتر (پیشنهاد: PHP همراه Herd)
- Composer
- فعال بودن افزونه‌های `pdo_sqlite`, `sqlite3`, `fileinfo`, `openssl`, `mbstring`, `xml`

## نصب در Laravel Herd

1. فایل ZIP را در مسیری مانند `C:\Users\YOUR_USER\Herd\warehouse-manager` استخراج کنید.
2. پوشه پروژه را به Herd اضافه کنید یا مطمئن شوید Herd آن را در پوشه Herd شناسایی می‌کند.
3. ترمینال را در ریشه پروژه باز کنید.
4. دستورهای زیر را اجرا کنید:

```powershell
composer install
Copy-Item .env.example .env
php artisan key:generate
New-Item -ItemType File -Force database\database.sqlite
php artisan migrate --seed
php artisan storage:link
```

اگر فایل `.env` از قبل وجود دارد، مرحله Copy-Item را رد کنید. اگر `database\database.sqlite` از قبل وجود دارد، دستور New-Item را می‌توانید رد کنید.

5. در Herd دامنه پروژه را باز کنید (برای نمونه `http://warehouse-manager.test`). مقدار `APP_URL` در `.env` را با دامنه واقعی هماهنگ کنید.

برای اجرای بدون Herd نیز می‌توانید از `php artisan serve` استفاده کنید.

## ورود اولیه

- نام کاربری: `admin`
- رمز عبور: `ChangeMe123!`

**بلافاصله بعد از اولین ورود، رمز عبور مدیر را تغییر دهید.** این اطلاعات فقط برای راه‌اندازی محلی اولیه است و نباید روی سرور با همین رمز باقی بماند.

## قابلیت‌های موجود در این نسخه

- ورود و خروج امن با نشست Laravel و هش رمز عبور
- کاربران فعال/غیرفعال و نقش‌ها
- مدیریت نقش‌ها و مجوزهای جزئی با Spatie Laravel Permission
- ساختار انبار ← راهرو ← قفسه ← ردیف
- شناسه عمومی UUID و QR Code برای هر ردیف
- تعریف کالا با SKU، بارکد و واحد شمارش
- تخصیص چند کالای مختلف به هر ردیف و ظرفیت نامحدود
- جابه‌جایی موجودی با کنترل مقدار موجود در تراکنش دیتابیس
- ثبت ورود، خروج و انتقال در تاریخچه عملیات
- نمایش درختی ساختار و موجودی
- ویرایش دستی نقشه دوبعدی اولیه با افزودن شکل و Drag & Drop و ذخیره مختصات
- رابط فارسی و راست‌چین واکنش‌گرا

## نکات مهم نسخه اول

- ویرایش اطلاعات برخی فرم‌ها و مدیریت پیشرفته کاربران/نقش‌ها در این نسخه هنوز رابط کامل ندارند؛ مسیرهای اصلی ایجاد و حذف و کنترل مجوزها پیاده‌سازی شده‌اند.
- نقشه فعلی ابزار طراحی آزاد دوبعدی است؛ شکل‌های نقشه هنوز به‌صورت خودکار به رکوردهای واقعی راهرو/قفسه/ردیف متصل نمی‌شوند. این اتصال در مرحله تکمیل نقشه انجام می‌شود.
- API و اپلیکیشن Flutter در این بسته پیاده‌سازی نشده‌اند و در مرحله بعدی باید بر اساس همین منطق و دیتابیس اضافه شوند.
- تاریخ‌ها در این نسخه با قالب پیش‌فرض میلادی نمایش داده می‌شوند؛ برای نمایش شمسی باید پکیج تاریخ جلالی سازگار با نسخه Laravel نصب و قالب‌ها به‌روزرسانی شوند.
- قبل از استفاده عملیاتی، بکاپ‌گیری، تست دسترسی‌ها و تست سناریوهای موجودی را انجام دهید.

## مجوزهای پیش‌فرض

مجوزها به صورت `resource.action` تعریف شده‌اند؛ مانند `products.view`, `products.create`, `inventory.assign`, `inventory.move`, `layout.design` و `qr.print`.

نقش‌های اولیه: مدیر کل، مدیر انبار، اپراتور، مشاهده‌کننده. نقش مدیر کل تمام مجوزهای seed شده را دارد.

## بازنشانی داده آزمایشی

دستور زیر تمام داده‌ها را حذف و Seed اولیه را دوباره اجرا می‌کند؛ فقط در محیط توسعه استفاده شود:

```powershell
php artisan migrate:fresh --seed
```


## تغییرات تکمیلی نسخه اصلاح‌شده

- انبار، راهرو، قفسه و ردیف دارای وضعیت فعال/غیرفعال و فرم ویرایش هستند.
- حذف هر سطح دارای زیرمجموعه از سمت سرور مسدود است؛ حذف ردیف دارای موجودی نیز مسدود می‌شود. این محدودیت وابسته به نقش کاربر نیست.
- ورود گروهی کالا از فایل‌های XLSX، XLS و CSV اضافه شده است. ستون‌های لازم `sku` و `name` هستند؛ ستون‌های اختیاری `barcode`، `unit` و `description` هستند. نام‌های فارسی «کد کالا»، «نام کالا»، «بارکد»، «واحد» و «توضیحات» نیز پذیرفته می‌شوند.
- برای ورود Excel کتابخانه PhpSpreadsheet اضافه شده است. چون فایل قفل Composer قبلی شامل این وابستگی نبود، فایل `composer.lock` حذف شده تا در اولین نصب وابستگی‌ها دوباره تولید شود.
- صفحه جزئیات ردیف، QR را با خروجی SVG نمایش می‌دهد و حالت چاپ اختصاصی برچسب دارد.
- ویرایشگر نقشه شماتیک امکان افزودن، جابه‌جایی، تغییر اندازه، چرخش، تغییر عنوان و حذف اجزای نقشه را دارد.
- صفحه کاربران دارای ویرایش، فعال/غیرفعال‌سازی و صفحه اختصاصی تنظیم نقش و مجوزهای مستقیم هر کاربر است. مدیریت نقش‌ها نیز از داخل صفحه کاربران قابل دسترسی است.

## نصب یا به‌روزرسانی در پروژه موجود

از پوشه پروژه در ترمینال Herd اجرا کنید:

```bash
composer install
php artisan optimize:clear
php artisan migrate
php artisan storage:link
```

اگر این بسته را روی پوشه فعلی پروژه کپی می‌کنید و فایل `composer.lock` قدیمی هنوز وجود دارد، به‌جای `composer install` این دستور را اجرا کنید تا وابستگی جدید Excel به lock اضافه شود:

```bash
composer update phpoffice/phpspreadsheet --with-dependencies
```

در یک استخراج تازه که `composer.lock` ندارد، `composer install` وابستگی‌ها را resolve و فایل lock جدید را تولید می‌کند. اگر Composer به‌دلیل محدودیت شبکه نتوانست بسته‌ها را دریافت کند، پس از برقراری دسترسی دوباره دستور مناسب را اجرا کنید.

**مهم:** در پروژه موجود از `php artisan migrate:fresh` استفاده نکنید؛ این دستور تمام جداول و اطلاعات فعلی را حذف می‌کند. دستور `php artisan migrate` فقط migration جدید وضعیت فعال/غیرفعال را اجرا می‌کند.

برای ورود Excel، اگر PhpSpreadsheet نصب نشده باشد، ابتدا نصب Composer را کامل کنید. نمونه فایل در `public/templates/products-import-template.csv` قرار دارد.

## یادداشت نقشه

ویرایشگر نقشه یک پلان شماتیک قابل طراحی دستی است. اجزای نقشه مستقل از رکوردهای واقعی انبار ذخیره می‌شوند؛ تغییر یک شکل در پلان، به‌تنهایی رکورد راهرو یا قفسه در دیتابیس را حذف یا ویرایش نمی‌کند.
